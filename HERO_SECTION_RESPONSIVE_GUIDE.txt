================================================================================

STEP 1: FIND THE BIG TITLE TEXT IN YOUR HTML
---------------------------------------------
1. Open your HTML file (e.g., about_us.html, For_education.html, etc.)
2. Press Ctrl+F (or Cmd+F on Mac) to open search
3. Search for your big title text (e.g., "ABOUT", "EDUCATION", "YOUTH", etc.)
4. You'll find something like this:

   <div class="framer-rqqsrm" ...>
     <div class="framer-jcul6d" ...>

         INITIATIVE

     </div>

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: Title still goes off screen
SOLUTION: 
- Check if you used the correct class name
- Make sure you added the CSS to BOTH mobile and tablet sections
- Clear browser cache and refresh

PROBLEM: Can't find the class name
SOLUTION:
- Search for your title text in the HTML
- Look for the nearest <div> with class="framer-xxxxx"
- The class name is usually 7-8 characters after "framer-"

PROBLEM: CSS not working
SOLUTION:
- Make sure you added !important to all properties
- Check that you're inside the correct @media query
- Verify the class name matches exactly (case-sensitive)

PROBLEM: Title too small or too large
SOLUTION:
- Adjust the clamp() values:
  - First value (80px): minimum size
  - Second value (22vw): scaling factor
  - Third value (200px): maximum size
- For larger titles, increase the max value (200px → 250px)
- For smaller titles, decrease the max value (200px → 150px)

WHAT THIS CSS DOES (Overlapping Text Fix):
================================================================================

1. .framer-1ebgzuc h2
   - Targets the "Join people who believe..." text
   - Makes it responsive with clamp()
   - Enables word wrapping (white-space: normal)
   - Centers the text
   - Prevents text from going off screen

2. .framer-5tvmqk-container
   - Container for the animated text
   - Makes it full width and centered
   - Ensures proper flexbox layout

3. .framer-J6ugj.framer-yfknkv
   - The text container wrapper
   - Limits max width to 95vw (mobile) or 90vw (tablet)
   - Centers content
   - Allows text to wrap properly

4. .framer-su7jo2
   - The "We are committed..." text below
   - Responsive font sizing
   - Proper spacing and centering
   - Word wrapping enabled

KEY PROPERTIES:
- white-space: normal → Allows text to wrap to multiple lines
- word-wrap: break-word → Breaks long words if needed
- overflow-wrap: break-word → Additional wrapping support
- text-align: center → Centers all text
- max-width: 95vw/90vw → Prevents text from going off screen
- clamp() → Responsive font sizing that scales with screen
